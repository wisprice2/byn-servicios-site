# Prompts de imágenes para tarjetas de servicios

Modo utilizado: generador de imágenes integrado. Caso de uso común: `photorealistic-natural`.

## Dirección visual compartida

Fotografía horizontal 3:2 para tarjeta web, estilo documental profesional y fotorrealista, contexto chileno, técnicos y herramientas creíbles, composición centrada apta para recorte responsive, luz natural o técnica limpia, materiales realistas, sin textos superpuestos, sin marcas de agua, sin riesgos laborales ni anatomía distorsionada. El logo BYN se usa como parche pequeño y fiel únicamente en una imagen por categoría.
